ПРОЕКТ: ПРОФЕССИОНАЛЬНАЯ ГЕНЕРАЦИЯ ДОГОВОРОВ

1. ЗАПУСК:
   - Запустите скрипт: python contract_batch.py
   - Программа сама создаст начальные данные, если их нет.

2. ПРОЦЕСС ГЕНЕРАЦИИ:
   - Ввод ФИО: Введите ФИО исполнителя. 
     * Авто-форматирование: "иван иванович" -> "Иван Иванович".
     * Ограничение: От 1 до 3 слов (при ошибке — повторный ввод).
     * Можно оставить пустым — тогда имена возьмутся из базы.
   - Количество: Введите любое число договоров (хоть 1000).

3. КЛЮЧЕВЫЕ ОСОБЕННОСТИ:
   - Профессиональный формат: Файлы .docx (MS Word) с таблицами и форматированием.
   - Умная нумерация: Программа находит последний файл в папке ready_contracts/ и продолжает очередь (60, 61, 62...).
   - Авто-обновление базы: Каждые 50 договоров программа сама генерирует новых случайных заказчиков — база никогда не кончается.
   - Реалистичные даты: Дата договора выбирается случайно за последние 5 месяцев.
   - Безопасность: Авто-очистка имен файлов от запрещенных символов.

4. РЕЗУЛЬТАТ:
   - Все договоры сохраняются в папку: ready_contracts/

5. ТРЕБОВАНИЯ:
   - Установленный пакет python-docx (pip install python-docx).
