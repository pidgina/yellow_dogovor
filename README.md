# ПРОЕКТ: ГЕНЕРАТОР ДОГОВОРОВ (Python)

## АВТОМАТИЧЕСКАЯ ГЕНЕРАЦИЯ
Программа создает профессиональные договоры оказания услуг в формате `.docx` (MS Word).
- **Автоматически генерирует данные клиентов** (ФИО, услуги, цены, даты).
- **Поддерживает непрерывную нумерацию** договоров.
- **Генерирует корректные даты** (дата договора совпадает с датой начала работ).

---

## ИНСТРУКЦИЯ ПО ЗАПУСКУ НА НОВОЙ СИСТЕМЕ (Windows / macOS / Linux)

### 1. УСТАНОВКА PYTHON
Убедитесь, что установлен Python 3.x.
[Скачать Python](https://www.python.org/downloads/)

### 2. УСТАНОВКА ЗАВИСИМОСТЕЙ
Откройте терминал (или командную строку) и выполните команду:
```bash
pip install python-docx
```
*(Если вы захотите вернуть генерацию подписей в будущем, понадобится также: `pip install pillow`)*

### 3. ЗАПУСК ПРОГРАММЫ
В терминале перейдите в папку с проектом и запустите:
```bash
python contract_batch.py
```
*(На macOS/Linux может потребоваться: `python3 contract_batch.py`)*

### 4. КАК ПОЛЬЗОВАТЬСЯ
1. При запуске программа предложит ввести **ФИО Исполнителя**.
   * Можно оставить пустым (нажать Enter) — тогда исполнители будут браться случайные из базы.
2. Введите **количество договоров**, которое нужно создать (например, 50).
3. Готовые файлы появятся в папке: `ready_contracts/`

---

## ФАЙЛЫ ПРОЕКТА
*   `contract_batch.py` — **ОСНОВНОЙ** скрипт генерации (стабильная версия).
*   `generator_clientov.py` — Модуль с базой имен и услуг (используется автоматически).
*   `contracts.csv` — Временная база данных (создается сама, можно удалять)..
